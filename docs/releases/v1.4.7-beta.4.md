# FUTO Voice Input 1.4.7 beta 4

Adds experimental Whistle recognition on top of beta 3. Existing models and
settings remain available; Orukeet remains the default.

## Whistle

- 16.9 MB download and installed model files, separate from runtime RAM.
- English, German, French, Spanish, Italian, Dutch and Polish, detected automatically.
- Final text after Stop. Download, select and delete it through Model Options.
- Offline ARM64 CPU inference with two threads. Each recording starts a separate
  worker process, which exits to release model memory. Cancellation stops it.
- Revision-pinned model and runtime with SHA-256 verification and Apache 2.0 notices.
- Optional English cleanup respects the detected language.

Install `futo-voice-input-moonshine-v1.4.7-beta.4.apk` over beta 3 without clearing
app storage. Application ID and release signing key remain the same; Android
version code increases from 72 to 73.

## Verification and limits

The release workflow requires JVM tests, lint, Android-test compilation, host
Whistle transcription/reload/silence/cancellation checks, signed ARM64 assembly,
and verification of the exact packaged Whistle runtime and its notices.

The pinned Windows runtime transcribed the repository's 7.43-second speech
fixture successfully. Locally, 52 focused JVM tests ran with no failures (one
host-runtime test skipped), dev-debug lint passed, and Android tests compiled.
The full Windows JVM run retained the two diagnostics-test failures already
documented for beta 3; the Linux release suite remains required.
Android device tests are included but have not been run:
no physical device was connected. Android speed, peak memory, accuracy,
microphone dictation and performance on slow phones remain unverified. The
Light rating is advisory, not a measured phone recommendation. Each recognition
includes a cold model load. Long recordings use the publisher's windowing.

Temporary audio and results stay in app-private cache, are excluded from
standard diagnostics, and are removed after success, failure or cancellation.
If the app process is killed, remaining scratch files are cleared on the next
nonempty Whistle run or by Android cache cleanup. Audio-history retention is
independent. Live transcription and manual language selection are not exposed.

Stable 1.4.6 remains the latest stable release.

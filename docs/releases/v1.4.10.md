# FUTO Voice Input 1.4.10

Promotes the beta tested by the maintainer to stable. App behavior is unchanged
from 1.4.10-beta.1.

- Keeps dictated content and raw error messages out of ordinary diagnostic
  reports and logs. Enforces retention for transcript captures and cached exports.
- Records actual text-delivery outcomes. Cancellation suppresses stale captures;
  failed cleanup preserves its raw stage and reason without claiming delivery.
- Adds clearer capture, recognition, model and history failure evidence.
- Adds **Transcript Cleanup → Rewrite preferences → Skip short transcripts**.
  It starts off. When enabled, eligible English text of 1–9 words skips S1-mini
  unless it contains fillers, correction phrases or repeated words. Basic cleanup
  and personal vocabulary still apply.

Install `futo-voice-input-moonshine-v1.4.10.apk` over the current app. Version code
82 updates both stable 1.4.9 and beta 1.4.10-beta.1. The application ID and signing
configuration are unchanged, preserving models, settings and recordings.

The [beta CI](https://github.com/Today20092/voice-input/actions/runs/40115084339)
passed 279 JVM tests with no failures or skips, lint, Android-test compilation,
reference checks, signed ARM64 assembly, APK contents/signature checks and separate
native-symbol verification. The maintainer reported that the beta checks looked
good and approved stable promotion. Release-tag CI repeats the automated checks
for this version. Builds run in CI under the low-memory workflow.

The experimental Moonshine runtime and S1 speculative decoding remain separate.
This release does not claim to resolve the affected-Poco Orukeet report or the
OnePlus Moonshine crash. Full device/benchmark coverage remains tracked in #15
and #17.

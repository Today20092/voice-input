# Harper English cleanup beta 1

This beta adds optional, offline Harper rules for English dictation. It keeps the history and diagnostics improvements from 1.4.4 beta 1. No recognition models were added or changed.

## Install and enable

Install the attached signed ARM64 APK over your existing app. It uses the same `org.futo.voiceinput.moonshine` package and release key. Version code 59 updates stable 1.4.3 and beta 1.4.4 without uninstalling or clearing settings, models, or history.

Open **Transcript Cleanup → Enable Harper cleanup**. Harper starts off; the conservative rules are preset when you enable it. No download is needed.

For English dictation with **Orukeet or Parakeet**, also enable **My automatic-language dictation is English**. These multilingual models do not report language to the app. Leave this declaration off if you switch languages. Known non-English results and text containing non-Latin letters bypass Harper even when the declaration is on. Mixed English with other Latin-script languages cannot be reliably distinguished by this guard.

Harper works with S1-mini turned off. If you enable both, the order is recognition, S1-mini, Harper, personal vocabulary, insertion. Existing S1-mini settings are preserved.

## What the defaults fix

- Extra ordinary spaces and spacing before sentence punctuation.
- Spacing around existing commas, while preserving numeric separators.
- Missing spaces between sentences.
- Lowercase `i` and existing contractions such as `i'm`.
- Sentence capitalization where Harper recognizes a sentence. Short fragments may be left alone.

The beta does not invent missing punctuation throughout unpunctuated speech. It does not change spelling, word choice, agreement, articles, or intentional repetition. In particular, it does not silently choose between `your/you're` or `were/we're`. Names and personal vocabulary, numbers, addresses, code, and line breaks receive additional protection. This is a conservative rules layer, not an S1-mini replacement for broad rewriting.

## Phone feedback

Try Harper with S1-mini off first. Compare the same saved recording with Harper off and on using Retranscribe. Retranscription replaces that recording's saved transcript, so copy any comparison text you want to keep first.

Try everyday English messages, names from your personal vocabulary, prices, dates, email addresses, contractions, and deliberate repetitions. Check both voice keyboard insertion and recognition popups. Then optionally try both S1-mini and Harper. Report unwanted changes as well as missed corrections.

Standard diagnostics record Harper duration, edit count, and whether it changed text, skipped it, or failed. They do not capture transcript text. There is no automatic upload and no new transcript history. Toggle Harper off to return to the existing behavior. Normal Android version checks prevent installing an older version-code APK over this beta; disabling Harper does not require downgrading.

## Build verification

GitHub Actions runs native rule regressions and the Android release unit tests, builds the ARM64 APK, checks that Harper and its dependency notices are packaged, and verifies the APK signature before upload. No local build, emulator, or device tests were run for this change. Phone behavior and speed need your testing before stable release.

Harper is pinned to 2.11.0. It runs on a background thread with bounded input and two correction passes. Unsupported language, excessive input, and handled cleanup failures preserve the input. Native process faults cannot be recovered by the Kotlin fallback. This beta is not promoted to the latest stable release.

# Stable release 1.4.2

This release brings the beta 18 features to the stable channel, including audio history and retranscription, optional S1-mini cleanup, organized settings, and bulk Personal Dictionary entry and import.

- Orukeet is the default recognizer for new installations. Existing saved model choices are preserved. Switch to Orukeet in Model Options to use it on an existing installation.
- The waveform uses the recorded amplitude directly. Adaptive gain is removed so older bars do not change height when you pause or speak louder. Immediate partial bars and the taller waveform remain.
- Public Issue Tracker and Send Feedback open this fork at Today20092/voice-input on GitHub. Send Feedback opens a new public issue.

## Installation

Signed standalone arm64 APK, version code 54. Install over beta 18 to retain settings, downloaded models, dictionary entries, and audio history. The application ID and signing configuration are unchanged. Do not uninstall or clear app data to update.

Models are downloaded separately. Orukeet downloads about 487 MB, installs about 672 MB, and needs about 1.16 GB free during installation. Recognition runs offline after download. Moonshine and the other recognizers remain available in Model Options.

The optional `arabic-transliteration.txt` download can be previewed and imported under Speech > Personal Dictionary. It is not enabled automatically.

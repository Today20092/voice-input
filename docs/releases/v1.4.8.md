# FUTO Voice Input 1.4.8

Fixes an intermittent Phonon 2 failure caused by full-volume negative audio samples.

## Phonon recording and recovery

Live recording and audio-history retranscription now convert PCM16 audio using
32,768 as the divisor. Previously, a valid sample of -32,768 became approximately
-1.0000305, outside Phonon's accepted [-1, 1] range. One such sample rejected the
entire recording before inference. Replaying the same saved audio repeated the
failure; switching to a recognizer without that strict check could succeed.

The fix also applies when opening recordings saved by older app versions.
No model download, uninstall, or deletion of saved recordings is needed.

## More useful diagnostics

Standard bug reports now distinguish invalid Phonon audio, native inference
failure, and JNI audio allocation failure. They continue to exclude audio,
transcripts, and exception messages.

The supplied report contained six Phonon failures, including three history
retries, 3–7 ms after recognition started with successful model loading. This is
consistent with the reproduced input-validation bug. Its older generic error
category cannot prove which audio samples were present or exclude other causes.

## Install and verification

Install `futo-voice-input-moonshine-v1.4.8.apk` over the existing app. Version code
79 preserves the production application ID and signing configuration.

The full-scale PCM history regression failed before the conversion fix and
passed afterward. Tests also check specific diagnostic categories without
exporting exception messages. Android regression coverage checks live sample
conversion and real Phonon recognition with a full-scale negative sample,
invalid-input rejection, and recovery afterward.

The release pipeline runs JVM tests, lint, Android-test compilation, reference
model checks, release assembly, and ARM64 APK content/signature verification.
Android instrumentation compilation does not execute the device tests. No
physical ARM64 device was connected for this fix; Samsung microphone and actual
Phonon inference confirmation remain pending.

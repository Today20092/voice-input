# FUTO Voice Input 1.4.7 beta 5

Includes Model comparison under **Advanced settings**, with a redesigned interface
and experimental Whistle support. Orukeet remains the default recognizer.

## Model comparison

- Record or import audio once, select models, and run the same audio through them.
- Separate Audio, Models and Results cards follow the app's settings design.
- Collapsible model families show download readiness, languages and selection counts.
- Review transcripts, decode times and error rates when a spoken reference is supplied.
- Listen to clips, edit their references, cancel a run, reopen saved comparisons,
  and export reports.
- Improved narrow-screen and large-text layouts, accessible controls and theme contrast.

This release includes the comparison feature that was missing from the published
beta 4 APK, along with Whistle in both Model Options and the comparison catalog.

## Whistle

- 16.9 MB model download; runtime memory is separate.
- Automatically detects English, German, French, Spanish, Italian, Dutch and Polish.
- Offline ARM64 CPU inference, with final text after Stop.
- A separate worker process loads the model for each transcription and exits to
  release it. Cancellation stops the worker.
- Pinned downloads, SHA-256 verification and Apache 2.0 notices.

Comparison results explain that every Whistle pass includes worker startup and
model loading. Repeated passes are not warm-model measurements; sampled app PSS
does not include the separate worker's memory.

Install `futo-voice-input-moonshine-v1.4.7-beta.5.apk` over an existing beta without
uninstalling or clearing storage. The application ID and production signing key
remain the same; Android version code increases from 73 to 74.

## Verification and limits

Local checks passed: focused JVM tests (70 passed, one optional host test skipped),
dev-debug assembly and lint, Android-test assembly, and 11 Android emulator UI/flow
tests. The UI checks cover narrow screens, large text, themes, model selection,
results and the recording/import workflow.

The signed release workflow requires the full Linux release JVM suite, lint,
Android-test compilation, host Whistle transcription/reload/silence/cancellation
checks, ARM64 assembly, APK contents and production signature verification.

No physical phone was connected. Whistle's Android inference, microphone dictation,
speed, peak memory, accuracy and behavior on slow phones remain unverified.
The Light rating is advisory, not a measured phone recommendation.

Stable 1.4.6 remains the latest stable release.

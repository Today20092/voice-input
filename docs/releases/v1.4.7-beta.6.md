# FUTO Voice Input 1.4.7 beta 6

Improves recording reuse and timing details in **Advanced settings → Model comparison**,
and fixes the passage jumping down when you press **Record**.

The passage stays in its original position. Stop, recording progress and Cancel
appear below it in the Audio card. Comparison runs still show progress near the
header. Includes all beta 5 models and features, including experimental Whistle.

Comparison model choices are all visible as checkboxes without expanding model
families. **Select none** clears every selection; **Select all** and **Installed
only** remain available. The normal Model Options page retains its layout.

Completed results now offer **Compare these recordings again**. Recordings and
references are copied into a new editable comparison, with model selections
retained and previous results preserved. They remain available after reopening
saved comparisons; deleting old results does not delete a reused comparison's audio.

Results show **Model load and setup**, **First transcription after load**,
**Load + first transcription**, and **Already-loaded transcription (median)**.
Loading includes backend setup and validation; download/conversion/report writing
are excluded. Already-loaded timing excludes load and one untimed warm-up.
Whistle starts a new worker for each pass: its repeated timings include worker
loading and are explicitly labeled; separate load and already-loaded timings are
unavailable for that runtime. Filesystem caches may be warm.

Install `futo-voice-input-moonshine-v1.4.7-beta.6.apk` over your existing beta
without uninstalling or clearing storage. The application ID and production
signing key remain the same; Android version code increases from 74 to 75.

## Verification

Dev-debug assembly, Android-test assembly, lint and all 19 benchmark JVM tests
passed locally. All 16 comparison UI/flow tests passed on the Android emulator,
covering recording reuse, preservation of prior results, independent audio copies,
invalid-audio rollback, direct model selection, Select none and timing labels.
Regression checks confirm that the passage position remains unchanged during
recording startup at normal text size and on a 320 dp layout with 200% text.
Screenshots were reviewed; displayed test-fixture timings are synthetic.

The signed release workflow requires release JVM tests, lint, Android-test
compilation, host Whistle checks, ARM64 assembly, APK contents and signature
verification.

No physical phone was connected. This UI fix does not establish Whistle's speed,
memory use or recognition accuracy on Android phones.

Stable 1.4.6 remains the latest stable release.

# FUTO Voice Input 1.4.6 Share beta 7

Beta 7 makes Model Options easier to browse and compare. It includes the full
catalog from beta 6, including Parakeet Redux, and retains the confirmed
Nemotron download fix. This release adds no new recognition backend over beta 6.

## What changed

- A selected-model card shows readiness and a clear Download or repair action.
- Models are grouped into **While you speak**, **Buffered updates**, and
  **After you stop**. Families are ordered by their smallest download within
  each group; variants use size order except Nemotron's shared-weight profiles.
- Every model uses the same card layout: name, languages, download size,
  unpacked model size, status, and an outlined Details button.
- Details use consistent labeled fields, scroll at large font sizes, and have
  visible buttons for model information and the actual app package where available.
- Cohere and Redux no longer have “Beta” in their model names. This label change
  does not establish comparative accuracy or measured phone performance.
- The FUTO Keyboard setup entry is hidden until a published upstream release
  supports this fork's provider setup. Its code remains available for restoration
  under [issue #16](https://github.com/Today20092/voice-input/issues/16).

**Download** is the amount transferred. **Model size** is the unpacked model
files stored on the phone, which can be larger than a compressed download.
It is not a measurement of RAM used while transcribing.

in [beta 6](https://github.com/Today20092/voice-input/releases/tag/v1.4.6-share-beta.6),
with a 213.3 MB packed CPU model. Its Android inference and comparative speed
still need device testing. Model Details link to sources and attribution;
[the model guide](https://github.com/Today20092/voice-input/blob/v1.4.6-share-beta.7/README.md#choose-a-model)
explains the options.

## Confirmed download fix

Nemotron 3.5 Multilingual downloads require only the four recognition files;
unused `test_wavs` samples no longer block completion. Nested download paths
are also supported. These fixes first shipped in beta 5 and remain included.

The [issue #7 reporter confirmed that downloading now works](https://github.com/Today20092/voice-input/issues/7#issuecomment-5966271935)
on October 3 (reviewed October 4). The reply does not identify the installed beta or confirm a
dictation test. Closure covers the reported download failure.

## Install and test

Install the attached signed ARM64 APK over the existing standalone app.
Application ID remains `org.futo.voiceinput.moonshine`; version code 68 upgrades
beta 6's 67. Do not uninstall or clear app storage: settings, downloaded models,
and history should be retained. The stable updater does not offer prereleases;
download this beta manually. The stable release remains unchanged.

Use it normally for a few days. Try the models and languages you use, opening
Details, selecting a downloaded model, and downloading a model you want to test.
If something fails, report the beta version, phone/Android version, model,
steps, expected result and actual result. Export a diagnostics ZIP through
Support if useful; review it before sharing. No audio or transcripts are
automatically uploaded.

## Verification and remaining work

Local release checks on October 4 passed: 205 JVM tests with zero failures and
one existing skip, standalone release lint, dev APK assembly and Android-test
assembly. Seven UI tests passed on the S25 Ultra: six catalog tests, including
large-font Details and legacy Whisper, plus the screenshot/group/size/source-button test.

Publication passed the release workflow's JVM tests, lint, Android-test compilation,
nine Harper Rust tests, signed standalone ARM64 assembly, native-library/notices
inspection and APK signature verification. The downloaded public APK's hash,
version code and existing release certificate were independently verified. See
[the successful release run](https://github.com/Today20092/voice-input/actions/runs/37222526334)
and [UI and publication evidence](https://github.com/Today20092/voice-input/blob/codex/parakeet-redux/docs/testing/share-beta7-ui-release.md).

This is a focused beta, not completion of all catalog calibration or phone
testing. Every model has consistent presentation, but every model has not been
downloaded and transcribed on the phone for this release. Hardware memory,
thermal and latency comparisons, headset/editor coverage, model-update lifecycle
checks and long-dictation testing remain open. The
[Poco no-speech report (#8)](https://github.com/Today20092/voice-input/issues/8)
also remains unresolved. GitHub issues #10–#16 retain their outstanding criteria;
this beta does not authorize a master merge or close those tickets.

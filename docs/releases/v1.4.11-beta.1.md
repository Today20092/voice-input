# 1.4.11-beta.1: Moonshine native-crash workaround

This beta uses the normal Voice Input app ID and release signing configuration.
Install it as an update to the normal app; existing settings, installed models,
recordings and personal vocabulary are preserved. Do not uninstall the normal
app to install this beta. The separate experimental Dev app remains separate.

## What changes

- Moonshine Small and Medium use the tested ONNX Runtime 1.23.0 build with
  KleidiAI disabled. It addresses the native illegal-instruction crash reported
  on OnePlus 15 without changing the Moonshine API or model files.
- Runtime and notice downloads are hash-pinned. Release checks verify the exact
  packaged runtime bytes, required symbol versions, ARM64/16 KiB compatibility,
  absence of SME/SME2 entry instructions and included licenses.
- S1 speculative decoding stays disabled. The normal release build explicitly
  turns it off, and APK checks reject the experimental native enabled-path
  marker. Existing transcript-cleanup settings are preserved.

## Evidence and limits

- Reviewed both new evidence ZIPs: [S1 results](https://github.com/Today20092/voice-input/blob/8e4145881e66cf544efecfe4d6e1c7406797c3b7/docs/testing/issue-40-oneplus-evidence-2026-10-24.md)
  and [Moonshine results](https://github.com/Today20092/voice-input/blob/8e4145881e66cf544efecfe4d6e1c7406797c3b7/docs/testing/issue-41-oneplus-evidence-2026-10-24.md).
  The OnePlus Moonshine evidence records successful live recognition, history
  retranscription and cancellation/recovery without a recorded native crash.
  Installed-build identity is a reporter declaration supported by retained CI
  provenance; the archive does not independently establish the original
  faulting instruction.
- The [S25 physical-device evidence](https://github.com/Today20092/voice-input/blob/6d7ba6a/docs/testing/s25-ultra-moonshine-runtime.md)
  covers Small and Medium, live partial/final results, actual saved-recording
  retranscription, cancellation/retry and same-process fallback switching.
  It used the Dev candidate; the local test-key re-signing preserved all
  non-signature payload entries. It is not a test of this normal signed beta.
- The OnePlus S1 benchmark showed no useful speed gain. The S25's additional
  290-word case was about 6.9% slower with speculation. These are standalone
  CPU experiments, so speculation remains an experiment rather than a default.

This beta still needs installation and recognition checks on the affected
OnePlus and the maintainer's phone before stable promotion. Older Android and
controlled external activity/IME receiver checks have not been completed.
No new microphone, emulator or device tests are claimed for the signed beta.

Build verification and the final APK checksum are recorded with the published
prerelease. Stable promotion is a separate decision; issues #40 and #41 remain
open.

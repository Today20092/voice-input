# FUTO Voice Input 1.4.7 beta 8

Long comparison passages now expand the text box to show every line. This also
applies to the editable words attached to each recording, including large text
settings.

The comparison page explains how to record multiple passages: choose a passage,
record it, then choose another and use **Record another**. Up to eight recordings
can be compared together. Each keeps its own reference, and every selected model
runs on all recordings. The confirmation shows how many recordings are included.

Recording durations now explicitly say **audio**, distinguishing audio length
from model transcription time. Beta 7's charts, timing tables, recording reuse
and Orukeet installation progress remain available.

## Installation and verification

Install `futo-voice-input-moonshine-v1.4.7-beta.8.apk` over the existing beta
without uninstalling or clearing storage. Android version code increases from
76 to 77; the application ID and production signing key remain the same.

Local app/test assembly, lint and all 21 comparison UI/workflow tests passed in
the Android emulator. Checks cover full-height passages at normal and 200% text
size, recording without moving the passage, and the three-recording comparison
confirmation. Screenshots were inspected. Physical-phone verification is pending.

Release CI runs release unit tests, lint, Android-test compilation, signed ARM64
assembly, pinned model checks and APK content/signature verification.

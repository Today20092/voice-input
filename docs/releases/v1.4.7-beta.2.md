# FUTO Voice Input 1.4.7 beta 2

This beta brings together ASR4ALL dictation, the Transcript Cleanup redesign,
and the compact voice-input panel. Orukeet remains the default. Existing model
selections and cleanup preferences are preserved.

## What changed

- **ASR4ALL Small, Medium and Large:** live English text with built-in
  punctuation, capitalization and small corrections. Models run offline through
  ExecuTorch after downloading about 38.6, 72.5 or 123.1 MB. The app uses the
  low-latency c16r4 tier. Plus variants are omitted because their extra speaker
  features do not help this dictation flow.
- **Automatic cleanup choice:** ASR4ALL's PCEC already cleans the transcript,
  so S1-mini is skipped when using these models. Its preference is retained for
  other recognizers. Basic text cleanup remains an independent option.
- **Simpler Model Options:** expandable model families and short summaries,
  with runtime information in Details.
- **Clearer Transcript Cleanup:** separate Basic text cleanup and AI rewrite
  cards, a before/after example, contextual English guidance, and expandable
  explanations. S1-mini download and preference controls remain available.
- **Smaller voice-input panel:** an audio-driven bar waveform with adjacent
  finish/cancel controls. The keyboard panel hides provisional text while
  recording; text-delivery callbacks remain intact. The separate recognition
  activity retains its larger layout and transcript preview. Permission,
  download and error prompts can scroll in short windows at large font sizes.
- **Documentation:** diagnostic coverage findings and follow-ups, recording
  benchmark scripts, and model benchmark planning are included in the source.

## Install

Install `futo-voice-input-moonshine-v1.4.7-beta.2.apk` over the existing app.
The production application ID remains `org.futo.voiceinput.moonshine`, with the
existing release signing key and version code 71. Keep app storage to retain
models, preferences and history. Stable 1.4.6 remains the latest stable release;
beta users should download this APK directly.

## Verification and limits

All three ASR4ALL models decoded a paced 11-second fixture offline on a Samsung
Galaxy S25 Ultra. Paced and whole-file results matched for each model, with
capitalization and punctuation. First partials appeared at roughly 2.4–2.9
seconds including test overhead. Native decoding, S1 bypass, composition
replacement and activity-result checks passed. See the
[ASR4ALL report](https://github.com/Today20092/voice-input/blob/v1.4.7-beta.2/docs/research/ticket-26-asr4all-feasibility-2026-10-09.md)
for measurements and their limits.

The cleanup rewrite passed its focused build, lint, unit and nine device checks
in its implementation thread. The compact-panel implementation passed review
and lint; its first device run passed 18 of 19 checks, with the remaining test
assertion corrected afterward. Portrait/landscape reruns were deferred by the
maintainer, who will test actual microphone dictation.

Two unchanged DiagnosticStoreTest cases fail locally on Windows. The GitHub
release workflow independently runs the existing unit, lint, native-license,
APK-content and signing checks before attaching the signed ARM64 APK.

Beta 1's build was canceled before publication after identifying the previous
CI packaging heap failure. Beta 2 raises the CI Java heap to 4 GB and limits
Gradle worker concurrency. The beta 1 tag is retained without a published APK.

Actual microphone dictation, TalkBack, full S1 download, broad accent/noise/name
accuracy, comparisons against Orukeet, and sustained thermal/battery behavior
remain unverified. A broader Whisper-selection navigation assertion remains
unresolved. This beta does not close those acceptance gates or the existing
[Poco no-speech report (#8)](https://github.com/Today20092/voice-input/issues/8).

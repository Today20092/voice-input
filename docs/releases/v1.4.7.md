# FUTO Voice Input 1.4.7

This stable release promotes the implementation tested in 1.4.7 beta 8. It adds
new offline models, on-device Model comparison, a compact recording panel and
clearer cleanup settings. Orukeet remains the default; existing model selections
and cleanup preferences are preserved.

## Find the best model for your phone

We recommend **Advanced settings → Model comparison** to choose a model for your
specific device, language and speech. Record two or three typical passages, or
import audio, then run the same recordings through your selected models. Check
each recording's words against what you actually said to get useful accuracy
scores. No model is the best choice for every phone.

- Compare up to eight recordings in one run, with a separate reference for each.
- See speed, word error rate and sampled app RAM charts at the top of results.
- Switch between already-loaded transcription time and loading plus the first run.
- Sort model details by speed, model-file size, word errors, RAM or run order.
- Read aligned metric tables, transcripts and individual repeated timings.
- Listen back, edit references, save comparisons and export JSON or Markdown.
- Use **Compare these recordings again** to reuse audio with different models
  while preserving earlier results. **Use as daily model** applies your choice.
- Select models directly, with **Select all**, **Select none** and **Installed only**.
- Long passages expand fully, and pressing Record keeps the passage in place.

Lower word error rate is better and requires an accurate reference. Already-loaded
speed sums each recording's median; startup speed includes setup and the first
decode of recording 1. Downloads and audio conversion are excluded. RAM is sampled
app-process PSS, including app overhead. Whistle reloads a separate worker for
every pass; its times include loading and its worker RAM is unavailable. Missing
measurements are labeled rather than ranked as zero. Fixed-audio results do not
measure live update latency or battery life. See the [comparison guide](../model-comparison.md).

## New recognition models

| Model | Languages and behavior | Model download |
| --- | --- | ---: |
| ASR4ALL Small | Live English text, built-in punctuation, capitalization and small corrections | 38.6 MB |
| ASR4ALL Medium | Live English text with the same built-in PCEC cleanup | 72.5 MB |
| ASR4ALL Large | Live English text with the same built-in PCEC cleanup | 123.1 MB |
| Phonon 2, experimental | English text after Stop, including punctuation and capitalization | 186.6 MB |
| Whistle, experimental | Text after Stop; auto-detects English, German, French, Spanish, Italian, Dutch and Polish | 16.9 MB |

These are file download sizes, not RAM requirements. ASR4ALL uses the mobile
ExecuTorch INT8 package and low-latency c16r4 profile. S1-mini is skipped for
ASR4ALL because it already applies PCEC; your S1-mini preference is retained for
other recognizers. Basic text cleanup remains independent. Phonon uses a separate
ARM64 CPU runtime with baseline and dot-product implementations. Whistle uses a
separate CPU worker that exits after each recording. Downloads and runtimes are
pinned and hash-checked, with their licenses and notices included.

All previous model choices remain available. The [model guide](../model-guide.md)
compares their language coverage, text behavior, storage, sources and available
performance evidence. A small download does not guarantee fast recognition or
low RAM use on every device.

## Recording, settings and downloads

- Model Options groups variants into expandable families with clearer summaries
  and Details. Comparison choices remain directly visible.
- Transcript Cleanup separates Basic text cleanup from AI rewrite, with a
  before/after example, English-language guidance and expandable explanations.
- The voice keyboard has a smaller panel with an audio-driven bar waveform and
  adjacent finish/cancel controls. It hides provisional text while recording;
  the separate recognition activity retains its transcript preview.
- Permission, download and error prompts can scroll in short windows at large text sizes.
- Orukeet and other compressed model packages show separate installation
  progress after download, plus verification/finalization activity. The screen
  stays awake during installation. Reaching 100% downloaded can still be followed
  by several minutes of unpacking; cancellation retains the archive for retry.

## Install and verification

Install `futo-voice-input-moonshine-v1.4.7.apk` over the existing stable or beta
without uninstalling or clearing storage. Android 8.0 or newer and ARM64 are
required. Version code 78 is higher than beta 8's 77. The production package
`org.futo.voiceinput.moonshine` and signing certificate remain the same, preserving
models, settings and recordings. GitHub's latest stable release is the source
for the built-in updater and Obtainium with prereleases disabled.

The maintainer reported that beta 8 looked good in phone use and requested this
promotion. The app implementation is unchanged from that beta. Beta 8's signed
release pipeline passed all 245 JVM tests with no failures or skips, release
lint, Android-test compilation, model-package/reference checks and ARM64 APK
content/signature verification. Its 21 comparison UI/workflow tests passed in
the emulator, including large text and multiple recordings. Earlier Android
checks exercised the real Orukeet archive through installation and activation.
The stable build runs the same release pipeline again.

These checks and the maintainer's everyday use do not establish a universal
speed, memory or accuracy ranking. Broad accent/noise coverage, TalkBack,
sustained thermal/battery behavior and all keyboard/headset combinations remain
incomplete. New runtimes retain their experimental labels. The existing
[Poco no-speech report](https://github.com/Today20092/voice-input/issues/8) and
other unrelated issue acceptance criteria remain open.

# FUTO Voice Input 1.4.7 beta 3

This beta adds experimental Phonon 2 English recognition on top of beta 2.
ASR4ALL, Transcript Cleanup, the compact voice-input panel and the existing
model choices remain available. Orukeet remains the default.

## Phonon 2

- English text after you stop recording, with punctuation and capitalization.
- The same Model Options card, Details, download, selection and deletion
  controls as the other recognition models.
- 186.6 MB download; 255.4 MB installed. Allow at least 442.1 MB free during
  installation. These figures describe files, not working memory.
- Runs offline using the pinned phonon-2-c native runtime with four CPU
  threads. Uses ARM dot-product instructions on supported processors and a
  baseline ARM64 implementation on older processors.
- Revision-pinned downloads, SHA-256 verification, and model/runtime credits.
- Optional Basic text cleanup and S1-mini remain available for its English
  transcripts. Phonon does not have ASR4ALL's built-in PCEC correction stage.

The model is by [Fermion Research](https://www.fermionresearch.com/models/phonon-2/),
derived from NVIDIA Parakeet TDT 0.6B v3 under CC BY 4.0.
This app uses the [phonon-2-c repackaging](https://huggingface.co/eschmidbauer/phonon-2-c)
and its MIT [C runtime](https://github.com/eschmidbauer/phonon-2-c).
The original publisher's 164 MB download is a different package.

## Install and try

Install `futo-voice-input-moonshine-v1.4.7-beta.3.apk` over beta 2.
The production application ID remains `org.futo.voiceinput.moonshine`;
version code increases from 71 to 72 with the existing release signing key.
Keep app storage to retain models, preferences and history.

Open Model Options, expand Phonon 2 and download it. Once ready, select it and
try a short English recording. Compare the same recording with Redux or
Orukeet. This is an optional experiment, not a change to the recommended model.

## Verification and limits

Both Android ARM64 runtime variants and the JNI bridge compiled with NDK
28.2.13676358 for API 26 and 16 KB page alignment. App and Android-test Kotlin
compilation passed locally. The host C runtime decoded the 7.43-second speech
fixture; the new catalog, presentation, gzip validation and real model-archive
installation checks passed. The full local JVM run had 214 tests, with the two
Windows DiagnosticStoreTest failures already documented in beta 2 and one
unrelated skip.

The release workflow requires the host transcription fixture, JVM tests, release
lint, Android-test compilation, signed ARM64 assembly, and native-library/notice
inspection before publishing an APK.

Android speed, memory use, microphone dictation and accuracy remain unverified.
No claim is made that Phonon is faster or more accurate than Redux on Android.
Long recordings use pause-based windows; cancellation waits for an in-flight
native decode before releasing the model. Low-memory native failures remain
a risk with this experimental runtime.

The Phonon integration is kept in commit `bce5255` so it can be reverted with
`git revert bce5255` independently of the beta version bump.
Reverting it makes a saved Phonon selection fall back
to Orukeet; downloaded files remain in app storage unless deleted first.
Stable 1.4.6 remains the latest stable release. This beta does not close the
device-testing limitations documented for beta 2.

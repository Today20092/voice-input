# FUTO Voice Input 1.4.6 Share beta 4

This prerelease retains beta 3 behavior and removes unused code identified by
the ponytail review. The standalone ARM64 APK has application ID
`org.futo.voiceinput.moonshine`, version code 65 and the existing release signer.

## Changes since beta 3

- Remove the unused staged-candidate readiness field and filesystem query.
- Remove an unused runtime-release entry point and unreachable runtime sweep.
- Remove the obsolete range-resume helper while retaining range-partition and
  download-resumption regression tests.

Model choices, defaults, session ownership, rollback, cancellation and terminal
OOM handling retain beta 3 behavior. No new model or automatic recovery is added.

## Testing and remaining work

Continue the [beta 3 phone test plan](v1.4.6-share-beta.3.md#what-to-test).
Physical phone/editor/FUTO Keyboard interoperability, headset routing, spoken
TalkBack, real-engine successor reload and notice clearance, long-dictation
measurements, catalog calibration and complete attribution remain open.
The isolated adapter remains outside production. Publication does not complete
those acceptance criteria or merge the integration branch into master.

GitHub's release workflow runs unit tests, lint, Android-test compilation, native
Harper checks, signed APK assembly and package/signature verification.

# FUTO Voice Input 1.4.5

App update checks now use this fork's GitHub releases instead of FUTO's update server. Install the signed ARM64 APK over your existing installation. Version code 61 keeps the same application ID and signing key, preserving settings and downloaded models.

## Changes

- Settings now offers **Check for updates** with checking, up-to-date, update-available, and failure messages.
- Manual and scheduled checks use this repository's latest stable release. Beta releases are excluded, and old cached FUTO update results are ignored.
- Update links open this fork's release APK for installation with Android's approval.
- The README includes Obtainium setup instructions for tracking releases.

Older APKs need this one manual update to receive the corrected updater. Download this release from GitHub or add `https://github.com/Today20092/voice-input` in Obtainium.

## Validation

The standalone release code compiled locally and four focused updater tests passed, covering numeric version comparisons, flavor suffixes, beta exclusions, APK link validation, and old cached results. The release workflow runs the standalone unit suite and native Harper tests, builds the APK, and verifies its packaging and signature before publication. The new settings flow has not been exercised on a phone.

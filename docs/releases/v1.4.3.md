# FUTO Voice Input 1.4.3

This release combines the history, Cohere Transcribe, and recognizer-popup betas
with app-wide local diagnostics and an S1-mini keep-warm fix.

## Install

Install the signed ARM64 APK attached to this release. It uses the existing
`org.futo.voiceinput.moonshine` app ID and release signing key. Version code 57
updates stable 1.4.2 and the tested betas while retaining settings and downloaded
models. Orukeet remains the default for new installations.

## Changes

- Audio history shows transcript previews. Clear history asks for confirmation,
  preserves recordings in use, and reports deleted, busy, and failed entries.
- Cohere Transcribe is available as an optional on-device recognition model.
  Select its recognition language explicitly. It downloads about 2.89 GB of model
  files and produces final text after Stop. It supports 14 languages, including
  Arabic and English; it does not detect languages automatically or stream text.
- The recognizer popup includes a model caption. Under Advanced, enable
  **Unobtrusive recognizer popup (beta)** to move it near the bottom and remove
  background dimming. This setting does not change the voice keyboard layout.
- App-wide diagnostics record technical events locally across recording, model
  loading, recognition, cleanup, delivery, and downloads. Collection has an off
  switch and Clear action. Detailed mode runs for up to 30 minutes.
- A manually shared bug-report ZIP includes a readable summary, structured
  records, device/build information, and content-free S1-mini reports. Standard
  collection excludes audio, dictated text, personal vocabulary, clipboard text,
  receiving-app names, raw Logcat, URLs, and exception messages. Notes entered
  into the report are included as entered. Transcript-inclusive exports remain
  separate. Evidence is bounded to seven days and 10 MB.
- S1-mini retains its service binding for the selected keep-warm duration, so
  successful cleanup does not immediately discard the loaded model.

## Verification and limits

The combined source passed `:app:testDevDebugUnitTest :app:lintDevDebug` on
2026-09-25: 127 tests, zero failures/errors, one skipped, and zero lint errors.
GitHub Actions runs release unit tests and builds and verifies the signed ARM64
APK before it is attached to the release.

The user tested history, Cohere downloads and recognition, and the popup beta on
a Samsung Galaxy S25 Ultra. No quantitative speed, memory, or accuracy benchmark
was collected, and no performance improvement is claimed for the popup.

Cohere uses substantial memory and may be slow or stopped on lower-memory phones.
Long recordings use chunks of up to 35 seconds, so words near chunk boundaries
deserve attention. The optional model retains its Beta label while broader device
testing continues.

Crash evidence is best effort. Delivery records describe Android accepting the
handoff; they cannot prove how another app displayed the text. Automated checks
do not replace device testing of diagnostic recording and sharing.

See [app-wide diagnostics](../diagnostics.md) and the
[Cohere model notes](cohere-beta.md) for details.

# FUTO Voice Input 1.4.6 Share beta 6

This beta adds optional Parakeet Redux recognition to
[Share beta 5](https://github.com/Today20092/voice-input/releases/tag/v1.4.6-share-beta.5).
It retains beta 5's dictation, history, model download, routing, and cleanup work,
including the Nemotron nested-download fix and microphone icon correction.

## Install and try Redux

Install the attached signed ARM64 APK over the existing standalone app. The
application ID remains `org.futo.voiceinput.moonshine`; version code 67 upgrades
beta 5's version code 66. Do not uninstall or clear storage. Settings and model
files are retained, and your existing model selection is preserved. Orukeet
remains the default. The stable updater does not offer prereleases.

1. Open Model Options and find **Parakeet Redux (Beta)**.
2. Download its approximately 213 MB packed model and select it.
3. Dictate a short phrase, then Stop to receive the final text. Redux does not
   show live partial transcripts in this app.
4. Compare the same quiet and noisy phrases with Orukeet, including the
   languages you use. Report your phone, Android version, transcript accuracy,
   and the delay after Stop. App diagnostics can help investigate failures.

## Why we added it

Redux compresses Parakeet's encoder into ternary weights, making it a useful
candidate for a smaller CPU recognizer. Moondream reports 113 times real-time
throughput on eight AMD EPYC cores and 38 times on an Apple M2 CPU using Photon.
Those are publisher desktop measurements, not speeds measured in this app.

Our Android integration uses the packed GGUF conversion and ARM NEON kernels
from parakeet.cpp, rather than Photon. The app download is 213.3 MB, compared
with Orukeet's approximately 486.8 MB compressed download and 671.7 MB installed
files. Download URLs are revision-pinned and the SHA-256 is verified before
installation. The native runtime uses a private GGML build to avoid conflicts
with S1-mini and legacy Whisper.

## Accuracy and CPU limits

Both Redux and Ultra support 25 European languages. In Moondream's matched
evaluation, Ultra has lower word error rates than Redux: 5.80% versus 6.55% on
the seven English sets, and 5.82% versus 9.04% in background noise. Ultra remains
a comparison model, not an additional app option in this beta.

Orukeet is a separate Parakeet adaptation. Its published pooled FLEURS result
uses different scoring and aggregation, so it cannot be directly ranked
against Moondream's mean FLEURS results. Its LibriSpeech test-other split was
also used for adaptation and checkpoint selection.

Android inference and speed have not been tested on a physical device here.
Phones with ARM dot-product support can use the NEON kernel; other ARM64 CPUs
fall back to a slower scalar kernel. Upstream has correctness checks for NEON
under emulation but no physical ARM speed measurements. This is an experimental
optional model, with no claimed Android advantage over Orukeet.

## Verification

Local checks on the beta.5-based source completed on October 4, 2026: 203 JVM
tests with zero failures and one existing skip, nine Harper Rust tests passed,
release lint, Android-test compilation, and ARM64 standalone APK assembly.
The APK manifest has version code 67 and the expected application ID. Native
package inspection confirms that Redux and Harper are included. Local builds
use the debug signing fallback; the attached release is signed by CI using
the existing release key.

The release workflow runs JVM unit tests, lint, Android-test compilation,
Harper native checks, signed APK assembly, and package/signature verification.
Redux's native library is included in the package checks. Android device smoke
tests are supplied for native loading and transcription of a speech fixture
after installing the model; these have not been run on a device here.

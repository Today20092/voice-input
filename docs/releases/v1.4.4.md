# FUTO Voice Input 1.4.4

Stable release combining the audio-history improvements and optional Harper English cleanup. Install the signed ARM64 APK over the existing app. Version code 60 updates both 1.4.4 betas without uninstalling; the package remains `org.futo.voiceinput.moonshine`.

## Changes

- Audio-history cards expose Copy, Retranscribe, and Delete directly. Truncated transcripts can expand, and Copy uses the full saved text.
- Diagnostics include history retranscription stages, waveform timing, build revision, and Harper timing/outcomes. Recorder shutdown no longer counts zero-byte reads as capture failures.
- Optional offline Harper rules handle limited English spacing, punctuation, and capitalization. Harper is off by default, needs no model download, and works without S1-mini. Existing preferences are preserved. Turn it off at any time in cleanup settings.

Speech models, S1-mini, personal vocabulary, and existing recordings remain available. A [removal guide](../harper-removal.md) records how Harper can be removed from a future build independently.

## Validation and limits

The Harper beta received one or two days of ordinary use on a Samsung Galaxy S25 Ultra with Orukeet and S1-mini disabled. The user reported no unwanted text changes, perceived slowdown, or reliability regression, and confirmed the upgrade preserved their setup.

The exported diagnostics contained 125 delivered dictations, including 85 with Harper completion records. Across 86 Harper runs, median Harper time was 25 ms, with a maximum of 1,029 ms. All runs reported zero edits, so this sample does not demonstrate improved accuracy. One short recording produced no text and followed the normal no-speech error path; the user reported no concern about it. The archive contains no dictated text or audio.

The release workflow runs native Harper regressions and Android standalone release unit tests, builds the ARM64 APK, and checks native packaging and its signature before publishing. Phone feedback applies to the beta's recognition behavior; this release changes version metadata, settings wording, and documentation. S1-mini combinations, multilingual behavior, personal vocabulary, and history actions were not deliberately exercised during this phone trial.

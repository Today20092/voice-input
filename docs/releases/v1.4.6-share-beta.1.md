# FUTO Voice Input 1.4.6 Share beta 1

This prerelease combines the existing ticket branches for testing on an ARM64
Android device. It uses application ID `org.futo.voiceinput`, version code 62,
and the existing release signing configuration. It is an update to the normal
app, not a separate beta installation. Android may prevent a direct downgrade
to version code 61. The stable in-app updater does not offer prereleases.

## Included changes

- FUTO Keyboard provider setup and updated keyboard help.
- IME text insertion bound to the current input session.
- Language controls that follow the selected model and clearer Model Options.
- Nemotron installation excludes test audio; interrupted model downloads retain
  resumable progress and explain when a file must restart.
- Moonshine reports backend failures and releases native state safely.
- Waveform and provisional transcript remain visible together.
- Explicit microphone selection, including supported Bluetooth routes, with
  interruption handling and recording-session ownership checks.

## What to test

1. Set up FUTO Keyboard, dictate into multiple apps, change fields, cancel, and
   confirm that text never enters a previous editor.
2. Change models and languages, inspect Model Options, and retry interrupted
   downloads without deleting valid files.
3. Check simultaneous live text and waveform in both the IME and recognition
   activity, including large text and TalkBack.
4. Select a real Bluetooth headset, disconnect it during dictation, and verify
   recording stops or recovers as documented without losing retained speech.
5. Run long Moonshine dictation and report the device, model, duration and result.

## Validation and remaining work

The release workflow gates publication on the combined standalone unit suite,
standalone lint, Android UI-test compilation, native Harper tests, signed APK
build and packaging/signature verification. Compiling UI tests does not mean
they ran on a device.

Integrated physical-device, headset, TalkBack and long-dictation checks are still
open. The existing emulator cannot currently install the app because of storage
constraints; its retained app data has been preserved. This beta is published to
collect those test results, not as a claim that every ticket is complete.

Safe manual model updates, reactive upgrade notices, bounded streaming recovery,
the transcribe.cpp adapter and its optional models are not part of this beta.
The separate intermittent-waveform report still needs a reproduction.

The remaining order and acceptance gates are recorded in
[`docs/plans/share-beta-finish.md`](../plans/share-beta-finish.md) and `tickets.md`.

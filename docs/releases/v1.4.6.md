# FUTO Voice Input 1.4.6

This stable release promotes Share beta 7 after the maintainer's continued everyday
use and testing. Recognition and UI code are unchanged from
`v1.4.6-share-beta.7`. Only release metadata and documentation changed.

## Included changes

- Model Options groups models by when text appears, with consistent cards,
  download sizes, unpacked model sizes, readiness and source links.
- Parakeet Redux remains available alongside the existing recognition models.
- Nemotron 3.5 Multilingual downloads no longer require unused sample audio,
  and nested model download paths are supported.
- The FUTO Keyboard provider setup entry remains hidden until an upstream
  release supports it.

Orukeet remains the default. Saved model selections are preserved. See the
[beta 7 notes](https://github.com/Today20092/voice-input/blob/v1.4.6/docs/releases/v1.4.6-share-beta.7.md)
for the full catalog, screenshots and prior verification.

## Installation

Install `futo-voice-input-moonshine-v1.4.6.apk` over the existing app.
The application ID remains `org.futo.voiceinput.moonshine`, and the existing
release signing key is retained. Version code 69 upgrades beta 7's code 68.
Keep app storage to retain settings, models and history.

This is the stable GitHub release used by the app updater and Obtainium.
Beta users can install the attached APK directly.

## Verification and known limits

Beta 7 passed 205 JVM tests with zero failures and one existing skip, release
lint, Android-test compilation, nine Harper Rust tests, signed ARM64 assembly,
native-library and notice inspection, and APK signature verification. Seven
catalog/UI tests passed on a Samsung Galaxy S25 Ultra running Android 16.
The maintainer subsequently reported good results during continued use.

The stable tag runs the same automated release checks before publication.
This promotion does not establish that every model works on every phone.
Redux Android inference, comparative memory/thermal/latency measurements,
headset/editor coverage, model-update lifecycle checks and long-dictation
coverage remain incomplete. The
[Poco no-speech report (#8)](https://github.com/Today20092/voice-input/issues/8)
remains unresolved. Outstanding GitHub issue criteria remain open.

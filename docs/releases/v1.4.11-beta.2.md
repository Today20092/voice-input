# 1.4.11-beta.2: Bundled ASR4ALL Medium and upstream sync

Install this beta as an update to the normal app. It uses the existing application
ID and production signing configuration; do not uninstall your existing app.
Settings, installed models, audio history and personal vocabulary are preserved.

## What changes

- ASR4ALL Medium is included for offline English recognition and is the default
  for new installations. Existing saved recognition-model choices are preserved.
- Legacy FUTO Whisper remains selectable and downloadable. Saved Whisper choices
  may require a model download because the old bundled English Whisper asset is
  no longer included. Included Medium needs space in the app's private cache.
- Includes the upstream IME fullscreen fix, updated development-app icons and
  updated Android build tools promoted through PR #50.
- Retains the Moonshine runtime workaround from beta.1. S1 speculative decoding
  remains disabled; optional recognition models and transcript cleanup remain
  available.

## Evidence and remaining checks

- Based on [PR #50](https://github.com/Today20092/voice-input/pull/50), whose
  [post-merge CI passed](https://github.com/Today20092/voice-input/actions/runs/41163741284).
- Historical device and bundled-model checks are recorded in the
  [included-model baseline report](../testing/asr4all-bundled-default-2026-10-30.md).
  They are not a fresh device run of this signed beta.
- Publication requires release CI to pass standalone release unit tests, lint,
  Android-test compilation, signed APK checks and native/model payload checks.
  Android-test compilation does not execute device tests.
- Before stable promotion, verify upgrading the production-signed app, ordinary
  dictation through an external keyboard, headset routing and interrupted real
  model downloads. No new phone or emulator checks are claimed for this beta.

This is a prerelease for testing. Stable 1.4.10 remains the latest stable release.
Deferred shared-recognizer adoption (#48) is excluded.

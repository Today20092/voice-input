# 1.4.11-beta.3 · Parakeet TDT 110M

Open **Model Options → Parakeet → Parakeet TDT 110M** to download and select this experimental English model. It runs offline and returns text after you stop recording. The download is 108 MB, the installed model uses 136.5 MB and installation needs about 245 MB of free space. ASR4ALL Medium remains the included default. Existing selections are preserved.

The official Sherpa-ONNX INT8 TDT package and its four model files were verified against the app's manifest. Sherpa-ONNX 1.13.4 transcribed the repository's English audio fixture on Windows. Comparative Android speed, accuracy and memory measurements are pending. [Model source and license](https://huggingface.co/nvidia/parakeet-tdt_ctc-110m) · [Research assessment](../research/parakeet-tdt-ctc-110m-assessment.md)

Install this prerelease over the production-signed app to keep existing data.

# FUTO Voice Input 1.4.7 beta 7

Adds comparison charts and clearer result tables, and fixes large model downloads
appearing stopped at 100% while their compressed files are still being installed.

## Comparison results

- An overview at the top shows speed, word error rate and sampled app RAM charts.
- Speed switches between already-loaded transcription and load-plus-first-run time.
- Sort model details by speed, model-file size, word errors, RAM or run order.
- Aligned label/value tables replace long timing paragraphs. Shared references
  appear once; repeated identical transcripts and summary values are removed
  from the detailed view. Exports retain every observation.
- Recording reuse, Select none, directly visible model choices and all beta 6
  models remain available. Orukeet remains the default recognizer.

Charts compare the same recordings. Loaded speed sums each clip's median;
startup speed measures loading and the first decode of recording 1. Word error
rate is weighted by reference word count and can exceed 100%. Missing or
incomplete measurements are not ranked as zero. RAM is sampled app-process PSS,
including app overhead, rather than model allocation size. Whistle's separate
worker reloads every pass, so its already-loaded and worker-RAM measurements
remain unavailable and are labeled explicitly.

## Orukeet installation

Receiving the 486.8 MB archive is only the download stage. Unpacking and checking
its model files takes additional time: the old screen left both bars full during
this work. The pinned published archive and all model checksums verified correctly.

The screen now shows separate installation progress, keeps the screen awake
during active installation, and shows ongoing verification/finalization activity.
Large compressed models may still take several minutes to unpack. Cancellation
cleans partial extraction while retaining the verified archive for retry; existing
installed files remain protected. The Orukeet model revision and hashes are unchanged.

## Installation and verification

Install `futo-voice-input-moonshine-v1.4.7-beta.7.apk` over your existing beta
without uninstalling or clearing storage. Application ID and production signing
key remain the same; Android version code increases from 75 to 76.

Release CI verifies the real pinned Orukeet archive and runs its installer test,
alongside release JVM tests, lint, Android-test compilation, host Whistle checks,
signed ARM64 assembly and APK contents/signature verification.

Local assembly and lint passed. The focused benchmark/downloader JVM suite had
47 passes and one unrelated optional archive test skipped. All 28 comparison and
downloader UI/flow tests passed. A separate Android fresh-install test used the
real cached archive through the download screen, checked live installation
progress and screen-awake behavior, and verified activation and every installed
file hash. That emulator test completed in 166.6 seconds. Network retrieval and
the archive hash were separately checked against the pinned publisher URL.

The supplied phone diagnostics identified the 100%-then-waiting symptom. The fix
still needs confirmation on that physical phone; emulator checks do not measure
phone inference speed, accuracy, memory peaks or thermals. Chart preview values
are synthetic fixtures. Stable 1.4.6 remains the latest stable release.

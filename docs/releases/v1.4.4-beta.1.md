# FUTO Voice Input 1.4.4 beta 1

Test build for [PR #3](https://github.com/Today20092/voice-input/pull/3). The PR remains unmerged. This prerelease does not replace 1.4.3 as the latest stable release.

## Install

Download the attached ARM64 APK and install it over this fork's existing app. It uses the same `org.futo.voiceinput.moonshine` app ID and release signing key. Version code 58 updates 1.4.3 while retaining settings, downloaded models, and unexpired recording history. Do not uninstall first.

Android normally blocks installing the older version-code-57 APK over this beta. Keep that in mind before testing; uninstalling would remove local app data.

## What to test

- Audio history exposes Retranscribe, Copy text, and Delete directly. Short transcripts have no redundant expansion button. Truncated previews offer Show full transcript, and Copy text copies the entire saved transcript.
- Check short and long recordings, dark/light themes, and your preferred text size. Action buttons wrap on narrow screens.
- Retranscribe saved recordings using different models. The new diagnostics record loading, recognition, cleanup, and completion separately from fresh dictation.
- For the intermittent waveform issue, enable detailed diagnostics, reproduce the behavior, note the entry point and visible symptom, then export the report. This beta adds first-waveform-frame timing, popup state, and Git revision to help investigate. It does not claim to fix the waveform issue.
- Canceling or resetting recording should no longer add a misleading recorder-read failure during normal shutdown.

The [phone test guide](https://github.com/Today20092/voice-input/blob/v1.4.4-beta.1/docs/phone-performance-test.md) provides speech passages, estimated speaking times, repeated runs, and diagnostic export instructions. Standard and detailed reports exclude audio and transcript text.

## Verification

The implementation passed 129 unit tests with zero failures and one existing skip, dev debug assembly, and lint. All 20 emulator checks passed, including history controls, full-text copying, diagnostic export, and waveform layout. The final shutdown-logging correction has a focused regression test. Phone microphone behavior and comparative model measurements still need device testing.

GitHub Actions builds this beta, runs release unit tests, and verifies the APK's release signature and ARM64 native libraries before attaching it here.

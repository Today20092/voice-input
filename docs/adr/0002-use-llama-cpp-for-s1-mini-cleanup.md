# Use llama.cpp for optional S1-mini transcript cleanup

Run the publisher's pinned Q4_K_M GGUF build of S1-mini by Superwhisper through a pinned llama.cpp Android runtime as an optional, English-only, on-device stage after final speech recognition and before personal vocabulary corrections. Download and hash-verify the model separately instead of bundling it in the APK. Build optimized ARM CPU variants plus OpenCL, choose the fastest validated backend with an on-device deterministic benchmark, retain CPU as the universal fallback, and run cleanup in a private secondary Android process so native or GPU-driver failures cannot take down the keyboard. This accepts a new native runtime, benchmark complexity, and post-stop latency to preserve offline processing, the publisher's documented prompt behavior, a reasonably sized APK, and reliable fallback across Snapdragon and Exynos devices.
